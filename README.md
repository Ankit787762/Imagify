#  Imagify
<img width="1865" height="852" alt="Screenshot 2026-09-17 174148" src="https://github.com/user-attachments/assets/d522e281-5245-438a-9dac-be3590eeeae8" />

Imagify is a MERN stack text-to-image generator web application that allows users to generate AI images from text prompts.

##  Features

-  User Authentication (Login / Register)
- Text-to-Image Generation
- Credit-based System
- Razorpay Payment Integration
- Fully Responsive UI

## Tech Stack

### Frontend
- React
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB

---

##  Installation & Setup

### Clone the repository

```bash
git clone https://github.com/Ankit787762/Imagify.git
cd Imagify
```

### 2️ Setup Backend

```bash
cd server
npm install
npm start
```

### 3️ Setup Frontend

Open a new terminal:

```bash
cd client
npm install
npm run dev
```

---

##  Environment Variables

Create a `.env` file in both frontend and backend with required keys:

### Backend `.env`
```
MONGO_URI=
JWT_SECRET=
RAZORPAY_KEY_ID=
RAZORPAY_SECRET=
```

### Frontend `.env`
```
VITE_BACKEND_URL=
```
